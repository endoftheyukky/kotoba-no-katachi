この作品は、入力されたことばを、文字の形、音、語や文の構造、文字どうし・語どうしの関係、意味から読み取り、一枚の視覚詩として紙面に組み立てます。

読み取った特徴は、繰り返す、離す、分ける、欠けさせる、傾ける、集める、余白をあける、といった操作としてことばそのものに加えられます。紙面に現れるのは、入力された字と、その字の中に見つかる形だけです。意味は図としては描かず、操作の強さや向きを決めるために使っています。

同じことばからは、読みと版が同じなら、いつも同じ紙面ができます。紙面にはそれぞれアドレスがあり、共有されたアドレスは、あとから開いても同じ紙面を表示します。作品を更新したあとも、以前に共有された詩はそのときの版のまま開きます。

コンクリート・ポエトリー、とくに新國誠一の視覚詩を参照しています。文字の形や音、配置、反復、空白も言葉の一部として扱う考え方をもとに、字形の計測や語の解析といった計算によって紙面をつくっています。

ことばは十六字まで。読みを指定するときは「子供の城（こどものしろ）」のように括弧で添えます。

記録について

ことばを入れて詩をつくると、そのことばと紙面が日時とともに記録されます。共有されたアドレスや作例を開いただけでは記録されません。

同じブラウザからの記録と、一度の訪問のなかでの順序がわかるよう、このブラウザに匿名のIDを保存します。記録には、名前・メールアドレス・位置情報は含まれません。

IPアドレスそのものは保存しません。不正な大量送信を防ぐため、IPアドレスから作った識別用の値を一時的に保持します。

記録は、この作品の運用と改善のためにのみ使います。仕組みの詳細は GitHub の技術文書にあります。
